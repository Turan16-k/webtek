# Web Teknolojileri Dersi Projesi

2025-2026 Bahar Dönemi – Kişisel Portfolyo Web Sitesi

## Sayfalar

| Sayfa | Dosya | Açıklama |
|-------|-------|----------|
| Hakkımda | `index.html` | Giriş sayfası, hobiler, medya, bağlantılar |
| Özgeçmiş | `cv.html` | Semantic HTML5 yapısı, timeline, beceriler |
| Şehrim | `sehrim.html` | Bootstrap Carousel (4+ resim), istatistikler |
| Takımımız | `takimimiz.html` | Spor takımı detayları |
| İlgi Alanlarım | `ilgi-alanlari.html` | API entegrasyonu |
| İletişim | `iletisim.html` | Form doğrulama (JS + Vue.js), PHP gönderimi |
| Giriş | `login.html` | PHP tabanlı kimlik doğrulama |

## Teknolojiler

- HTML5 (Semantic tags)
- Bootstrap 5.3
- CSS3 (harici dosya)
- JavaScript (Vanilla)
- Vue.js 3 (form doğrulama)
- PHP (sunucu tarafı)

## Kurulum

PHP destekli bir sunucu gereklidir (XAMPP, WAMP vb.).
