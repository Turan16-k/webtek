## Proje Hakkında

Semantik HTML5, Bootstrap 5, JavaScript, Vue.js 3 ve PHP kullanılarak geliştirilmiş kişisel tanıtım web sitesi.

## Sayfalar

| Sayfa | Dosya | Açıklama |
|-------|-------|----------|
| Hakkımda | `index.html` | Kişisel tanıtım, hobiler, medya |
| Özgeçmiş | `cv.html` | Semantic HTML5 ile eğitim ve deneyim |
| Şehrim | `sehrim.html` | Tokat – Bootstrap Carousel slider |
| Takımımız | `takimimiz.html` | Galatasaray Spor Kulübü |
| İlgi Alanlarım | `ilgi-alanlari.html` | TVMaze API entegrasyonu |
| İletişim | `iletisim.html` | Form + Vue.js & Vanilla JS validasyonu |
| Giriş | `login.html` | PHP kimlik doğrulama |

## Kullanılan Teknolojiler

- **HTML5** – Semantik etiketler (header, main, section, article, aside, footer)
- **Bootstrap 5.3** – Responsive tasarım, Navbar, Carousel
- **CSS3** – Harici stil dosyası (`css/style.css`)
- **JavaScript** – Form validasyonu (`js/main.js`)
- **Vue.js 3** – CDN ile form validasyonu (ikinci buton)
- **PHP** – Sunucu taraflı form işleme ve login sistemi
- **TVMaze API** – Ücretsiz, anahtarsız REST API

## Kurulum

1. Projeyi XAMPP/WAMP `htdocs` klasörüne kopyalayın
2. Apache sunucusunu başlatın
3. Tarayıcıda `http://localhost/proje/` adresini açın
